# University Stats

University Stats is a student companion for schedules, attendance, points, and academic progress. This repository contains the editable source projects for Android and iOS.

## Projects

- `android/` — Kotlin, Jetpack Compose, Gradle. Open this folder in Android Studio and run the `app` configuration.
- `ios/` — SwiftUI, Xcode. Open `ios/MySibSutis.xcodeproj` on macOS. Select your own signing team when running on a physical device.

Both apps keep user data on the device. The source folders do not include build outputs, local machine settings, sample schedules, or the original archive files.

## Русский

University Stats помогает студентам работать с расписанием, посещаемостью, баллами и успеваемостью. В репозитории лежат полные редактируемые проекты для Android и iOS.

- `android/` — Kotlin, Jetpack Compose и Gradle. Откройте эту папку в Android Studio и запустите конфигурацию `app`.
- `ios/` — SwiftUI и Xcode. Откройте `ios/MySibSutis.xcodeproj` в Xcode на macOS. Для запуска на физическом устройстве укажите свою команду подписи.

Данные пользователя остаются на устройстве. В репозитории нет результатов сборки, настроек конкретного компьютера, учебных расписаний с личными данными или исходных ZIP-архивов.
