# University Stats — Android

Нативная Android-версия текущего iOS-приложения University Stats.

## Основа переноса

Эталоном поведения служит текущий исходник iOS-приложения из `UntiversitySats.zip`:
- 5 разделов: Главная, Посещаемость, Баллы, Успеваемость, Настройки;
- расписание и переключение недель;
- первая/вторая неделя учебного года;
- лекция/практика/лабораторная/занятие;
- подгруппы;
- отметки «Я на паре» / «Не был»;
- таймер пары с 45 минутами + 5 минутами перерыва + оставшимися 45 минутами;
- статистика посещаемости;
- баллы, история, комментарии и автомат;
- контрольные недели 1–4 и две сессии;
- локальное хранение данных;
- уведомления о контрольных неделях.

## Импорт расписания на Android

Основной пользовательский сценарий — **не HTML-файл**.

1. Откройте страницу расписания университета в Chrome.
2. Нажать **Поделиться**.
3. Выбрать **University Stats**.
4. Приложение получает URL страницы.
5. Сначала выполняется прямой HTTP-запрос.
6. Если страница не распознаётся или сайт требует браузерную сессию, автоматически используется WebView.
7. WebView получает уже отрендеренный `document.documentElement.outerHTML`.
8. Парсер извлекает `days[1] ... days[14]`, `ScheduleCell`, `Subgroup`, `DISCIPLINE`, `TEACHER`, `CLASSROOM`, `GROUP`, `SUBGROUP`, `TYPE_LESSON`, `DateBegin`, `DateEnd`.
9. Расписание сохраняется локально.

Также есть ручной ввод URL внутри раздела **Настройки → Импортировать из сайта**.

## Важно

Проект использует Gradle 9.6.0 из исходного Android Studio проекта. Финальную Gradle-сборку нужно выполнить в Android Studio с доступом к Maven/Gradle repositories: текущее окружение сборки не имеет DNS-доступа к `services.gradle.org`, поэтому здесь невозможно честно заявить о локально выполненном `assembleDebug`.
